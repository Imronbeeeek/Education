## Method & reliability
- Rules were researched in October 2026 against official university and government pages, mostly via search-engine extracts. Several official sites (anabin, Nuffic, universityadmissions.se, Maastricht, MOFA Korea) were not directly reachable from the research environment.
- Each country file states a **confidence level** and a "verify" list, and cites its sources.
- Admissions rules change every cycle. **Get written confirmation from each admissions office before paying an application fee**, especially for:
  - Uzbek-specific recognition at Dutch WO, Danish and Australian universities
  - the Spanish homologation outcome
  - Korean university-specific 12-year wording
  - Gulf private-sector equivalence
- "All institutions" coverage is **rule-based**. Each country's recognition rule applies uniformly to every institution of a given type (public university, applied-sciences university, private, branch campus, arts academy, military, women-only). Each file lists institutions by name as completely as practical (full lists for small and medium systems; all major and exception institutions for very large ones).
